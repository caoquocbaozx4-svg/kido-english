# Kido English V4

Mã nguồn đầy đủ website học tiếng Anh, gồm frontend, backend Worker, tài nguyên, migrations và scripts build.

## Tải mã nguồn

Mở **Releases**, chọn bản **Kido English V4**, tải tệp **Kido-English-V4.zip** trong **Assets** rồi giải nén.

```sh
npm ci
npm run build
```

Đọc `DEPLOYMENT.md` trong gói để cấu hình Firebase, quản trị viên, D1, R2 và hosting mới. Mã dự án Sites đã được bỏ khỏi gói chia sẻ. Không kèm node_modules, Git history hoặc cấu hình môi trường riêng.

Đây là kho lưu gói mã nguồn; tải lên GitHub không tự triển khai website hay kết nối Firebase. Tài khoản, tiến độ và dữ liệu runtime trên hosting cũ không nằm trong gói.
